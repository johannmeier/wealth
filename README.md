# Beschreibung
Mit diesem Programm kann das eigene Vermögen einfach aufgelistet werden.

Es können folgende Dinge erfasst werden.

1. Wertpapiere
   - börsengehandelte 
   - Edelmetalle
   - sonstige z.B. Altersvorsorge (Riester, Arbeitgeber usw.) ohne automatischen Kursabruf
   - automatischer Abruf von Kursen der börsengehandelten Wertpapiere und der Edelmetalle
2. Konten mit Währung
3. In Depots werden die Wertpapiere verwaltet
4. Daueraufträge für Wertpapiere

- Bei Wertpapieren kann stichtagsbezogen eine neue Anzahl eingetragen werden.
- Bei Konten kann stichtagsbezogen ein neuer Saldo eingetragen werden.
- Bei den ETFs und Fonds kann der Index angegeben werden.
- Bei allen Wertpapieren können Wertpapierart angegeben werden. z.B. Aktie, Aktienfonds, ETF, Anleihe, Währung
- Bei allen Wertpapieren kann die Asset Allocation angegeben werden. z.B. Risikobehaftet, Risikofrei

# Historie
Es wird der Kurs eines Wertpapiers des 1ten eines Monats gespeichert, damit eine Historie angezeigt werden kann.
z.B. Wie hoch war mein Vermögen im Januar 2022?

# Statistiken
Es können folgende Statistiken angezeigt werden:

1. Auflistung der Wertpapiere, dann Konten und gesamt Summe.
2. Auflistung der Wertpapiere und Konten nach Index.
3. Auflistung der Wertpapiere und Konten Wertpapierart. 

Für jede Position der Positionen einer Auflistung wird der Prozentanteil am Gesamtvermögen der Wertpapiere und Konten angezeigt.
