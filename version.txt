Wealth – Release History
========================

Version 1.0.5  (2026-06-04)
-----------------------------
Securities
  - Distribution policy (Distributing / Accumulating) added as a new attribute
  - Asset search: ISIN shown in search results dropdown
  - Asset search: distribution policy, asset allocation and security type
    pre-filled automatically from the Yahoo Finance result name and type
    (bond keywords → Risk-Free; Acc/Accumul → Accumulating; Dist/Income → Distributing)
  - Asset allocation pre-fill respects the configured base currency:
    bond ETFs in a foreign currency remain Risky

Banks
  - New Bank entity groups accounts and depots
  - Bank list shows combined total per bank with expandable rows
    displaying individual accounts and depots with values
  - Bank detail page (/banks/{id}) with collapsible account and depot
    sections, subtotals and grand total
  - Accounts and depots can be assigned/removed from the bank detail page
  - Deleting a bank is blocked while accounts or depots are assigned to it

Accounts & Depots
  - Accounts and depots can optionally be linked to a bank
  - ISIN shown next to security name in depot positions form and table
  - Account list falls back to legacy bank name string for accounts not
    yet linked to a Bank entity


Version 1.0.4  (2026-06-04)
-----------------------------
Bug Fixes
  - Wealth history: coin values were always shown as 0 even when coins
    are present; fixed by replacing entity proxy access with pure ID maps
    and correcting the quantity fallback when no historical record exists
    before a given month
  - Wealth history: coins without CoinQuantity history (created before
    v1.0.2) now correctly use their current quantity for all months
  - Outdated notice "coin quantities are not tracked historically"
    removed from the history page


Version 1.0.3  (2026-06-04)
-----------------------------
Correctness
  - Non-EUR accounts are now properly converted to EUR before being
    included in total wealth and statistics calculations
  - Wealth history: precious metal coins without a linked security now
    use historical price data instead of the current spot price

Performance
  - Each statistics page called getAllPositions() twice per request
    (including 6 Yahoo Finance HTTP calls instead of 3); now computed once
  - N+1 queries in AccountService, DepotService and AssetService replaced
    with bulk queries

Data Consistency
  - Price history: upsert logic — at most one entry per security per day
    (multiple updates on the same day update the existing entry instead of
    inserting a new one)
  - Asset quantity and coin quantity: same upsert logic per date
  - Daily price refresh (18:00 scheduler, manual button) now also writes
    a price history entry
  - 674 duplicate price history rows removed from the database

Robustness
  - fetchPrice() now throws an exception when Yahoo Finance returns no
    valid price (prevents storing 0 as the current price)
  - updatePrices() no longer holds a database connection open during
    external HTTP calls
  - Failed spot price fetches are now logged instead of silently ignored

Security
  - H2 database console disabled (was accessible without authentication)

Build
  - Maven Compiler Plugin explicitly configured for Java 21 (fixes
    IntelliJ "JVM target 5" error)


Version 1.0.2  (2026-06-03)
-----------------------------
History & Data Quality
  - Historical wealth view (/statistics/history): monthly chart and table
    showing total wealth over time, broken down into securities, accounts
    and coins
  - Coin quantity history (CoinQuantity entity): date-based snapshots per
    coin; auto-recorded on save; manageable via /coins/{id}/quantities
  - Monthly price snapshots now fetched from Yahoo Finance historical API
    on startup to backfill any months missed while the app was not running
  - Prices refreshed from Yahoo Finance on every startup (not only at 18:00)
  - Price history entries are only written by monthly snapshot jobs, not
    by daily price refreshes (no more duplicate entries)
  - Monthly price history entries marked with a badge in the price history view

UX & Forms
  - Asset search: ISIN is now filled from Yahoo Finance search result
  - Coin form: asset (price source) is now required; selecting a metal
    auto-suggests a matching asset from existing coins
  - Dropdown in coin list no longer clipped on odd rows (replaced
    filter: brightness() with background-color to avoid stacking context)

Cleanup
  - Standing Orders feature removed
  - Mockito agent configured in Maven to suppress self-attach warning


Version 1.0.1  (2026-06-02)
-----------------------------
Settings & UI
  - Settings menu in navbar: language, color scheme, display currency
  - Language switch: German / English
  - Color scheme: Light, Dark, System (follows OS preference)
  - Configurable display currency: any 3-letter ISO code (EUR, USD, GBP, CHF, ...)
    All monetary values are converted from EUR to the selected currency;
    account balances show both display currency and native account currency
  - Locale-aware number formatting (e.g. German decimal comma)
  - Accessibility improvements across all pages

Platform & Distribution
  - Platform-specific data directory:
      Windows  → %APPDATA%\Wealth\
      macOS    → ~/Library/Application Support/Wealth/
      Linux    → ~/.config/wealth/
  - System tray icon with show/hide and quit actions
  - Info page showing version, config path and database path
  - MIT license

Layout
  - Unified widescreen table layout across all pages
  - Fixed dashboard layout (labels left, values right)


Version 1.0.0  (2026-06-02)
-----------------------
Initial release.

Core tracking
  - Securities: exchange-traded (stocks, ETFs, bonds, funds, crypto, currencies,
    precious metals) and manual (e.g. pension plans without automatic prices)
  - Automatic price updates via Yahoo Finance at startup and weekdays at 18:30
  - EUR conversion for non-EUR securities using live exchange rates
  - Asset archiving and restore (history is retained)
  - Asset search via Yahoo Finance (name, ISIN, WKN)

Accounts & Depots
  - Bank accounts with individual currencies and date-based balance snapshots
  - Depots (portfolios) grouping securities with date-based quantity snapshots
  - Editable depot positions

Physical Precious Metals
  - Coin management for gold, silver and platinum
  - Weight entered in grams; automatic troy ounce conversion
  - Optional link to a security as EUR/oz price source
  - Spot prices fetched live from Yahoo Finance as fallback
  - Coins integrated into statistics and depot positions

Statistics
  - Dashboard: all positions with quantities, prices and wealth percentages
  - By allocation (Risky / Risk-Free)
  - By index (MSCI World, S&P 500, ...)
  - By security type (ETF, Stock, Bond, ...)
  - Collapsible detail rows in statistics views

History
  - Monthly price snapshots for all securities (1st of each month)
  - Full balance and quantity history per account and depot
